# Robotic Test Automation Showcase (PWA)

A responsive, installable single-page prototype dashboard for an AI-assisted
robotic test pipeline — tablet/mobile-first, works on iOS, macOS and desktop
browsers. No build step, no dependencies: plain HTML + CSS + JS.

## Run locally

Any static file server works. From this folder:

```bash
python3 -m http.server 8080
# or: npx serve .
```

Then open http://localhost:8080

> Note: service workers require `http://localhost` or HTTPS — opening
> `index.html` directly via `file://` will not install the offline cache.

## Deploy to GitHub Pages

1. Push this folder to a GitHub repository (root or `/docs`).
2. Repo → Settings → Pages → Source: *Deploy from a branch*, pick your branch.
3. Open the published URL on your phone and use **Add to Home Screen**
   to install it as an app.

## Install as an app (PWA)

- **iOS/iPadOS Safari:** Share → *Add to Home Screen*.
- **macOS Chrome/Safari:** address-bar install icon, or *File → Add to Dock* (Safari).
- **Android Chrome:** menu → *Install app*.

## What's mocked

Everything is a prototype simulation — no real test runner is involved:

- **Play / Pause / Stop / ⏮ / ⏭** bottom bar drives a 20-second simulated run.
- As the run progresses: log lines stream in, screenshots unlock,
  the mock video player runs, and progress fills on the *Test Run* card.
- At 100% the **Test Report** unlocks with mock pass/fail stats and a
  browsable `.xls` table.
- PDF cards, file explorer and business-value cards open mock modals.

## Files

| File | Purpose |
|---|---|
| `index.html` | Page structure: workflow cards, 2×2 detail panel, control bar, modals |
| `styles.css` | Theme, layout, responsive breakpoints, safe-area handling |
| `app.js` | Playback engine, log streaming, modals, screenshots/video states |
| `manifest.webmanifest` | PWA install metadata |
| `sw.js` | Cache-first service worker for offline use |
| `icons/` | SVG + PNG app icons (generated by `tools/generate-icons.js`) |
| `tools/generate-icons.js` | Zero-dependency Node script that rasterizes the PNG icons |

Regenerate icons with:

```bash
node tools/generate-icons.js
```
